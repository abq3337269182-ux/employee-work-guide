主持：把一场直播衔接好。

紫色条款旁的“待确定”表示尚未定案，不作为新增执行依据。

返回岗位选择

主持负责现场调度，直接向运营总监汇报。主播的日常管理由直属运营负责。

准备控场收尾业绩设备

提前60分钟到岗，先对接运营。

到岗与检查节点

提前60分钟主持到岗，对接运营，确认当日直播安排。
提前30分钟主持组织主播进入直播间，检查服装、妆造与状态，拍截图发团群。

主持向运营核对

直播人员、重点目标舞蹈顺序、站位与BGM游戏、互动和PK等当日环节分配账号、设备和软件

主持把配合准备齐

主持
核对道具、假发、服装、音效、背景音乐和配合暗号。
主持 → 运营
发现设备或主播状态影响直播，及时沟通，由运营协调。
主持
确认舞蹈课安排，提醒主播按时参加。

舞蹈课迟到处理 待确定

原要求：舞蹈课迟到者在工作群发30元红包，由主持监督。

当前拟删除红包与主持监督要求；拟删除不等于已经删除。

串联环节，让每位主播有展示机会。

直播中主持做什么

主持
完成开场暖场、报幕，串联舞蹈、游戏和互动。
主持
合理分配展示机会，关注弹幕、在线情况、礼物和直播节奏。
主持
按平台规则感谢礼物、引导关注，及时处理弹幕争吵与现场失误。
主持 → 运营
同步重点用户业务信息，报告直播异常。
主持
发现安全或平台违规风险，先暂停风险动作，再与运营对接。

监督关机和归位，再组织复盘。

主持的收尾交接

  1. 主持监督主播有序下播，监督软件退出和设备关闭。
  2. 主持监督个人物品及使用区域整理归位。
  3. 运营、主持组织主播参加简短复盘。
  4. 主持录制复盘视频，发到团群。

日常协作

主持
记录舞蹈课到场和迟到情况，反馈直属运营。
主持
核对粉丝维护完成情况。发现问题记录事实，反馈运营。
主持
配合舞蹈、妆造和摄影岗位，协调直播、排练和拍摄时间。

直播间整体清扫 待确定

当日业绩最低的主播负责直播间整体清扫。

拒不执行时，同时扣对应考核分与月度积分。

每日作业与下班 待确定

拟保留：主播完成每日作业后才能下班，由主持检查。

尚未定案；不解释为可以强行限制人员离开。实际工时、加班和紧急例外仍需明确。

下班前填报，之后逐级核对。

主持每日业绩表

  1. 主持使用运营总监提供的模板，登记直播间整体及每位主播业绩、票数流水。
  2. 主持下班前将当日业绩表提交团群。
  3. 直属运营复核主持填报的数据。
  4. 运营总监终审数据。未终审的表，不进入正式核算。
  5. 行政将终审后的每日业绩表按月归档。

数据错了，不直接覆盖

  1. 主持备注修改原因，保留原记录和修改痕迹。
  2. 运营、运营总监确认更正。电子表保留痕迹，纸质表签字确认。

主持监督操作，不随意改软件。

现场操作依据

主持监督设备操作按现场核实后的操作单完成。保存位置和软件按钮，以现场操作单为准。

直播软件或参数不擅自升级、修改。确需变更，由运营协调验证稳定性后安排。

设备异常的交接

主持 → 运营
反馈设备硬件异常，由运营协调专业人员。
主持 → 运营总监
排期或指令冲突交总监协调。主持请假报运营总监。
